# Schedule-Web

**Plan your day by turning your time into flexible blocks.**

A fast, minimal, calendar-style daily planner. Create time blocks of any duration (not just presets), drag to move, drag the edge to resize, and everything is saved automatically in your browser.

## Getting started

```bash
npm install
npm run dev
```

## Tech

- React + TypeScript + Vite
- Tailwind CSS
- Local storage persistence (swappable for a real backend later — see `src/lib/storage.ts`)
